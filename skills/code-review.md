## Code Review Scope

Only raise an issue if it could change the program's output or behavior (wrong value, wrong branch
taken, crash, data loss, incorrect clinical/scientific result). Do not raise:
- Style, naming, formatting, or comment nitpicks.
- Missing tests or missing docstrings.
- Refactor/cleanup suggestions with no behavior impact.
- Anything a linter, type checker, or CI would already catch.

If genuinely unsure whether something changes output, say so briefly rather than omitting it, but do
not pad the review with low-confidence or cosmetic findings.
